# 2026-10-04 http 모듈

- `modules/http` 추가: URL(RFC 3986), 헤더/값 파서(미디어 타입, Link, Content-Range, WWW-Authenticate, Basic),
  HTTP/1.1 클라이언트(keep-alive 풀, 리다이렉트, 타임아웃, Range, 유닉스 소켓, HTTP(S)_PROXY/NO_PROXY, CONNECT 터널)와
  서버(라우터, 한도, keep-alive, chunked 요청 본문, 정상 정지). core는 고치지 않음.
- TLS는 tls 모듈이 동시에 만들어지고 있어 의존하지 않고 `ITlsConnector` 훅으로 분리함. 테스트는 전송 스트림을 그대로
  돌려주는 대역 훅과 테스트 안의 작은 프록시로 https 경로와 CONNECT 터널을 검증.
- 본문은 `IStream`(`IBodyReader`)으로 노출하고 버퍼가 비면 호출자 버퍼로 바로 읽게 해 큰 blob을 버퍼링하지 않음
  (64 MiB 다운로드 중 RSS 증가 약 0.5 MiB).
- 발견해서 고친 문제:
  - `http+unix` 호스트(소켓 경로)를 소문자로 바꾸면 경로가 깨짐: http/https와 스킴 없는 참조에서만 호스트를 소문자로 바꿈.
  - spawn된 `serve()`가 시작되기 전에 `stop()`을 부르면 serve가 정지 플래그를 지워 끝나지 않음: 플래그를 serve 끝에서 지움.
  - 읽지 않은 입력이 남은 채 오류 응답 뒤 소켓을 닫으면 RST로 응답이 사라질 수 있음: lingering close 추가.
- ASan/UBSan 빌드에서 http 테스트 전부 통과. IPv6 루프백이 없는 환경이라 IPv6 왕복 테스트는 건너뜀(MESSAGE).
