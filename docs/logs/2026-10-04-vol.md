# 2026-10-04 vol 모듈

## 한 일

- `sbox::vol` 모듈을 새로 만들었습니다(의존: archive, http).
  - Docker와 같은 디렉터리 배치의 볼륨 저장소(`<root>/<name>/_data`, `volume.json`, `opts.json`, `state.json`),
    flock으로 프로세스 간 직렬화, 사용자 id 기반 참조 계수, 재부팅 감지(boot id), 익명 볼륨, prune.
  - `local` 드라이버 옵션(Docker 검증 규칙 그대로), tmpfs/NFS/bind/장치 마운트와 첫 사용 마운트·마지막 해제
    언마운트, NFS `addr=` 이름 해석, copy-up.
  - 프로젝트 쿼터(`FS_IOC_FSSETXATTR`, `quotactl_fd`/`quotactl`, XFS와 generic 명령).
  - tar.gz 백업/복원(파일, 싱크/소스, 코루틴 스트림), fsfreeze 옵션.
  - `-v`/`--mount`/`--tmpfs`를 OCI 마운트 JSON으로 바꾸는 변환과 `PrepareContainerMounts`.
  - Docker 볼륨 플러그인 핸들러 `CVolumePlugin`.
- CLI: `sboxvol`(볼륨 명령 + `serve` 플러그인 데몬), `sboxnet`(net 모듈 `CDockerPlugin`을 HTTP 서버에 연결).
  두 데몬 모두 signalfd를 이벤트 루프에서 기다려 정상 종료합니다.
- 테스트 7개 실행 파일. 마운트는 포크한 자식의 사적 마운트 네임스페이스 안에서만 합니다.

## 결정과 메모

- Docker처럼 같은 이름으로 다시 만들면 기존 볼륨을 그대로 돌려줍니다.
- 볼륨 플러그인 오류는 HTTP 200 + `Err`, 모르는 경로는 404. sboxnet은 net 문서 권고대로 오류에 500을 씁니다.
- 지우기 전에 언마운트하고, 그래도 마운트 지점이면 지우지 않습니다(bind 출처, NFS 내보내기 보호).
- 이 환경 커널에 `CONFIG_QUOTA`가 없어 ext4는 `quota`/`project` 기능이 있는 이미지를 마운트할 수 없었습니다.
  쿼터 한도 테스트는 조건을 확인하고 건너뜁니다. ext4 장치 볼륨과 freeze 백업은 루프 장치로 실제 확인했습니다.
- 테스트에서 코루틴 람다를 루프 안의 지역 변수로 spawn하면 람다 객체가 먼저 사라져 캡처가 깨집니다. 매개변수를
  가진 자유 코루틴 함수로 바꿨습니다.
