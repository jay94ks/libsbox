# 2026-10-04 archive 모듈

- 범위: DEFLATE/zlib/gzip 해제·압축, zstd 해제, tar 읽기·쓰기(ustar/PAX/GNU), 안전한 추출과 레이어
  whiteout, 디렉터리 → tar, 동기/코루틴 스트림 배관. 외부 라이브러리 없이 직접 구현.
- 코덱 인터페이스를 zlib `z_stream`식 동기 상태 기계(`ICodec::process`)로 정함. 같은 코덱을 fd 동기
  파이프라인과 `IStream` 코루틴 파이프라인 양쪽에서 쓰기 위함.
- inflate: 10/8비트 루트 테이블 + 서브 테이블, 64비트 비트 버퍼, 입력이 짧을 때 심볼 단위 스냅샷
  롤백. 256 KiB 창 버퍼에서 32 KiB만 남기고 밀기. 처리량이 python zlib과 같거나 조금 높음.
- deflate: zlib 레벨 표, 32비트 전역 위치 해시 체인(밀 때 테이블 수정 불필요), 블록마다
  stored/fixed/dynamic 비용 비교. 길이 제한은 처음에 잎만 overflow로 세는 실수가 있었고, zlib처럼
  깊이 초과 노드 전부를 세도록 고쳐 Kraft 합이 항상 정확해짐(피보나치 빈도 테스트 추가).
- zstd: 창 + 블록 + 여유분 크기의 버퍼를 블록 단위로 순환하며 직전 세그먼트를 확장 사전처럼 참조.
  wild copy가 아직 필요한 옛 데이터를 덮지 않도록 순환 조건에 여유분(MARGIN)을 둠.
- 픽스처: python zlib/gzip/tarfile, python-zstandard(스크래치 디렉터리에 pip로 설치해 오프라인 생성)로
  만들어 바이트 배열로 넣음. 평문은 C++과 파이썬의 같은 xorshift32 생성기로 재생성. 생성 스크립트는
  `modules/archive/tests/fixtures/gen_fixtures.py`.
- 추출: openat2(RESOLVE_IN_ROOT)와 O_NOFOLLOW 걷기(대체 경로)를 둘 다 테스트. 마지막 성분은 항상
  지우고 새로 만듦. 디렉터리 mode/시간은 끝에 적용. whiteout은 overlay / overlay userxattr /
  apply 세 정책.
- 검증: Debug(-Werror), AddressSanitizer, UndefinedBehaviorSanitizer로 `ctest -L archive` 통과.
  무작위 손상(gzip 1500, zstd 3000, tar 3000회)에서 크래시 없음.
- core 변경 없음.
