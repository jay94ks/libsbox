# 2026-10-04 net 모듈

- netlink를 직접 구현: 메시지/속성 빌더와 파서, 시퀀스 번호로 응답을 구분하는 비동기 요청/ACK, 덤프,
  nfnetlink 배치, 확장 ACK. 한 소켓의 동시 요청은 코루틴 대기열로 직렬화.
- 다른 netns 작업 방식 결정: 소켓/장치 파일은 만들 때의 netns에 묶이므로 `CNetnsScope`로 잠깐 `setns`해
  디스크립터만 만들고 바로 복귀. `co_await` 너머로 유지 금지, 복귀 실패는 abort. 전부 netns 안에서 해야
  하는 일은 `CNetns::run`(fork + pidfd).
- nftables는 `inet sbox` 테이블 하나를 "add; delete; add" 배치로 통째 교체해 원자성과 멱등성을 얻음.
  루프백 포트 매핑은 route_localnet + 127/8 masquerade(Docker userland-proxy=false 방식).
- IPAM은 Docker default-address-pools와 같은 기본값, JSON 상태 + flock. 여러 프로세스 동시 할당 테스트 추가.
- DHCP 클라이언트는 packet 소켓으로 직접 IP/UDP를 만들어 주소 없는 인터페이스와 다중 클라이언트를 지원.
- 드라이버 인터페이스는 Docker 원격 드라이버 생명 주기(create/join/leave/delete)를 따르게 해 Docker 플러그인
  핸들러와 CNI, box/oci 계층이 같은 코드를 쓰게 함. macvlan의 DHCP는 호스트 netns의 임시 인터페이스에서
  임대를 받은 뒤 샌드박스로 이동.
- 이름 충돌: core의 `sbox::SEndpoint`(소켓 주소)와 겹치지 않도록 네트워크 엔드포인트 타입은
  `SNetworkEndpoint`로 함.
- 개발 환경 커널: `ipv6.disable=1`, dummy·ipvlan 없음 → 해당 테스트는 확인 후 건너뜀, macvlan 부모는 veth.
- 모든 커널 테스트는 임시 netns 안에서만 수행(호스트 역할도 임시 netns), 호스트 네트워크 변경 없음 확인.
- Docker 플러그인의 HTTP 서버 연결과 사용자 공간 네트워킹(slirp)은 남은 작업.
